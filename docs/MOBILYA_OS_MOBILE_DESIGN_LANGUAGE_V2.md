# MOBILYA OS Mobile Design Language V2 (Locked)

Status: Official and mandatory
Date: 2026-08-02

Bu dokuman kilitlenmistir.
Bu tarihten sonra tum mobil ekranlar bu tasarim dilini zorunlu olarak kullanir.

## Temel Kural

IsCep mobil uygulamasinin gorunumu kopyalanmaz.
Sadece UX dusunme bicimi ve kalite seviyesi referans alinir.

MOBILYA OS kendi kurumsal kimligini korur.

## Referans Alinacak Prensipler

- White space
- Typography hierarchy
- Navigation flow
- Search-first yaklasimi
- List-first information architecture
- Component consistency
- Minimal shadow
- Neutral surfaces
- Soft radius
- Premium spacing
- Reading flow
- Touch ergonomics
- Apple HIG uyumlu yerlesim
- Tek tip list row yapisi
- Tek tip card yapisi
- Ayni component'in her yerde ayni gorunmesi

## Referans Alinmayacak Unsurlar

- IsCep renkleri
- IsCep ikonlari
- Finans terminolojisi
- Menu birebir kopyasi
- Marka kimligi
- Gorsel birebir benzerlik

## Tasarim Dilinin Hedefi

MOBILYA OS mobil deneyimi su kalite cizgisinde olur:
- Apple HIG
- Material 3
- Linear
- Notion
- IsCep seviyesinde UX kalitesi

## Uygulama Kurallari

- Tum mobil ekranlar ayni tasarim dilini kullanir
- Eski ekran makyajlanmaz
- Gerekirse ekran sifirdan yeniden tasarlanir
- Component tutarliligi zorunludur
- Token disi yerel tasarim karari alinmaz
